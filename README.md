# SwapSway

SwapSway enables real-time data synchronization across distributed nodes, ensuring fault-tolerant operation on scalable server systems.

With SwapSway, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/SwapSway.git`
2. `cd SwapSway`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SwapSway, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
